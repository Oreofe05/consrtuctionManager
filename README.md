# BuildControl – Construction Project Management System

BuildControl is a web-based construction project management system designed to improve the way construction projects are planned, coordinated, managed, and monitored. Developed as a Computer Science project, with the University of Ibadan serving as the case study, the system provides a centralized platform for managing essential construction project activities and maintaining project-related information.

The platform brings together key project management operations, allowing users to create and manage projects, assign tasks, monitor schedules and deadlines, manage resources such as labour, materials and equipment, track project expenditures, and monitor overall project progress. It also provides a dashboard for viewing important project information, helping users keep track of ongoing activities and make more informed management decisions.

BuildControl aims to reduce the challenges associated with managing project information across separate processes by providing a more organized and accessible approach to construction project management. Through its different modules, the system supports better coordination, information management, accountability, and monitoring throughout the project lifecycle.

The application is developed using **React** and **Tailwind CSS** for the frontend, **Node.js** and **Express.js** for the backend, and **MongoDB** for database management. These technologies work together to provide a responsive web application with integrated backend services and centralized data storage.

**Key Features**
- Project creation and management
- Task and activity assignment and tracking
- Project scheduling and deadline monitoring
- Labour, materials, and equipment management
- Project expenditure and budget tracking
- Project progress monitoring
- Dashboard and project summaries
- User authentication and access control
- Centralized project information management

BuildControl is intended to serve as a practical digital solution for improving the organization, coordination, and monitoring of construction projects.
